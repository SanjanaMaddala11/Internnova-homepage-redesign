# InternNova Homepage Redesign

## About the Project
This project is a modern, responsive redesign of the InternNova homepage, developed as part of a web development internship task.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Responsive design for desktop and mobile devices
- Modern homepage layout and typography
- Internship program cards
- Interactive navigation and website sections
- FAQ section and call-to-action

## How to Run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.
